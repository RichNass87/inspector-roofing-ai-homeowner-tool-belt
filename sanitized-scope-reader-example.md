# Sanitized ScopeReader™ Example

This is a fictional example. Do not publish real homeowner documents.

## Input summary

A homeowner uploads a roofing estimate containing line items for tear-off, underlayment, starter shingles, ridge cap, waste, ventilation, pipe boots, flashing, labor, and debris removal.

## ScopeReader™ output concept

### Plain-English summary

This estimate appears to describe a full asphalt shingle roof replacement. It includes removing the existing shingles, installing new underlayment, installing new shingles and ridge materials, and handling disposal.

### Terms to understand

- **Roofing square:** 100 square feet of roof surface.
- **Waste factor:** extra material for cuts, valleys, hips, rakes, and mistakes.
- **Ridge cap:** shingles designed for roof ridges.
- **Pipe boot:** flashing around plumbing vent pipes.

### Questions to ask

1. Does the estimate include ventilation upgrades?
2. Does it include starter shingles and ridge cap as separate materials?
3. Does the estimate include code-required items?
4. Is decking replacement included or only priced if discovered?
5. Is the warranty based on manufacturer requirements?
