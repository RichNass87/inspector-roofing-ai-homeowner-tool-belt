# No-Code Publication Notice

This repository is intended for public research, documentation, schema examples, and white paper materials only.

Do not publish:

- application source code
- backend code
- API keys
- model prompts
- production workflows
- webhook URLs
- contractor agreements containing live language without legal review
- signed agreements
- customer documents
- uploaded scopes
- private estimates
- manufacturer data files not cleared for public use

Recommended approach:

- Public repo: documentation, schema examples, sanitized examples, white paper.
- Private repo: production code, prompts, model orchestration, customer upload handling, backend, webhooks, logging, storage, and evaluation.
