# Privacy Principles

The public documentation repository must not contain private user data, homeowner uploads, insurance claims, signed agreements, real estimates, internal prompts, API keys, webhook URLs, production code, or personally identifiable information.

## Product privacy principles

1. Minimize collected data.
2. Explain what each tool collects before collection.
3. Use sanitized examples in public documentation.
4. Separate public documentation from private production systems.
5. Do not publish homeowner uploads or signed agreements.
6. Use server-side logging and storage only where approved.
7. Review retention and deletion policies with counsel.

## ScopeReader™ privacy note

Uploaded estimates and scopes may contain personal, property, carrier, claim, and financial information. Public examples must be fictional or fully sanitized.

## Inspector AgreementFlow™ privacy note

AgreementFlow™ may create signature images, PDF files, confirmation IDs, signer timestamps, browser metadata, and form data. Treat all signing records as sensitive business records.
