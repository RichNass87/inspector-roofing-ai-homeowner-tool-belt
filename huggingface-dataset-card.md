# AI Homeowner's Tool Belt Public Source Map

This public-safe dataset card documents the source map for **AI Homeowner's Tool Belt**, a roofing homeowner decision-support software and research package developed by **Richard Amir Nasser** and published by **Inspector Roofing and Restoration**.

The package connects a GitHub repository, DOI-backed Zenodo record, Microsoft Store identity, Chrome Web Store review record, ORCID profile, and Inspector Roofing website schema target. It is designed as a public entity-clarity package, not as a dump of production code, customer data, app secrets, or private dashboard records.

## Tool Components

- ScopeReader: roofing estimate and scope explanation support.
- Roofmatch: roof color and manufacturer-option discovery support.
- Inspector AI Roof Plan Assistant: inspection planning and checklist support.
- InstantRoofView: homeowner-friendly budget preview support.
- Inspector AgreementFlow: agreement workflow and audit-trail support.
