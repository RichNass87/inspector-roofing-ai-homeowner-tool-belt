# Implementation Roadmap

## Phase 1: Entity lock

- Finalize tool names.
- Create canonical URLs.
- Create one-sentence definitions.
- Add trademark notation.
- Confirm safety boundaries.

## Phase 2: Landing pages

- Publish individual pages for each tool.
- Add visible disclaimers.
- Add screenshots and examples.
- Add schema.
- Validate schema.

## Phase 3: Public proof layer

- Publish GitHub documentation repository.
- Add `CITATION.cff`.
- Add white paper.
- Add source notes.
- Add sanitized examples.
- Release `v0.1.0`.

## Phase 4: DOI and distribution

- Connect GitHub repo to Zenodo.
- Create GitHub release.
- Mint DOI.
- Update white paper with DOI.
- Publish LinkedIn article and website page.

## Phase 5: AEO expansion

- Create demo videos.
- Add transcripts.
- Add glossary cluster.
- Add tool comparison pages.
- Add case-study pages that show knowledge gaps being solved.
- Monitor Search Console query classes and tool-branded search demand.
